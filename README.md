# Resume Builder

Reusable instructions for building accurate, ATS-readable resumes with a restrained single-column A4 design and mandatory quality checks.

## Files
- [SKILL.md](SKILL.md) — source-grounded resume writing, formatting, export, and audit standards.

## Use
Give your AI assistant this raw URL and the candidate's own source materials:
https://raw.githubusercontent.com/Ri-el/resume-builder/main/SKILL.md

Suggested prompt:

> Read and follow the resume-generation instructions at https://raw.githubusercontent.com/Ri-el/resume-builder/main/SKILL.md. Use the attached candidate information and latest corrections. Create a restrained single-column A4 resume, perform factual, content, and rendering QA, and deliver only the format I request. Do not invent facts.

## Privacy
Do not add real candidates' personal details, resumes, phone numbers, addresses, or certificates to a public repository.

## Limitations
These are instructions, not a resume-generation application. The assistant still needs suitable document-generation and PDF-rendering tools to create and inspect files.
